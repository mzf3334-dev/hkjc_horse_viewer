# HKJC Horse Viewer — Production Specification

> Version: 1.0  
> Replaces: spec.md (prototype draft)  
> Status: **Approved — development in progress**

---

## 1. Overview

A two-repo system:

| Repo | Purpose |
|------|---------|
| `mzf3334-dev/hkjc_scraper` | Python scraper + GitHub Actions pipeline. Produces all data files. |
| `mzf3334-dev/hkjc_horse_viewer` | Static GitHub Pages viewer. Reads data files. No backend. |

The viewer only talks to `raw.githubusercontent.com` — no CORS issues, no server required.

---

## 2. Architecture

```
hkjc_scraper repo
├── hkjc_scraper_github.py   # existing — scrapes race results after race day
├── scrape_racecard.py       # NEW — scrapes today's race card entries (before races)
├── merge_csv.py             # NEW — merges all dated CSVs → data/all_results.csv
├── .github/workflows/
│   └── scrape.yml           # NEW — scheduled GitHub Actions (2 jobs/day)
└── data/
    ├── hkjc_results_YYYYMMDD.csv   # one file per race day (existing)
    ├── all_results.csv             # NEW — merged history, rebuilt after each scrape
    └── racecard_today.json         # NEW — today's upcoming race entries, rebuilt each morning

hkjc_horse_viewer repo
└── index.html               # NEW — production single-file app (replaces prototype.html)
```

## 4. `scrape_racecard.py`

### Purpose
Scrape today's race card from the HKJC SPA, output `data/racecard_today.json`.

### Source URL
```
https://racing.hkjc.com/zh-hk/local/information/racecard
```

### Behaviour
1. Launch headless Chromium via Playwright.
2. Navigate to the race card URL.
3. Detect today's date and venue (ST / HV). If no race today → write empty JSON, exit 0.
4. For each race number found in the race selector:
   - Click to load that race's entries.
   - Extract: race_no, distance, going, and per-horse fields (horse_no, horse_name, jockey, trainer, weight, gate).
5. Write `data/racecard_today.json`.
6. Print summary to stdout (picked up by GitHub Actions log).

### Output path
`data/racecard_today.json` (relative to repo root, same directory as CSVs).

---

## 5. `merge_csv.py`

### Purpose
Merge all `data/hkjc_results_YYYYMMDD.csv` files into `data/all_results.csv`.

### Behaviour
1. Glob `data/hkjc_results_*.csv`, sort by filename (= date order).
2. Write header once.
3. Append all data rows (skip header row of each file).
4. Print row count to stdout.

### Run after every scrape
The GitHub Actions results job runs `merge_csv.py` immediately after `hkjc_scraper_github.py`.

## 6. GitHub Actions — `.github/workflows/scrape.yml`

Two scheduled jobs per day (times in UTC; HKT = UTC+8):

| Job | Cron (UTC) | HKT | Purpose |
|-----|-----------|-----|---------|
| `scrape-racecard` | `0 22 * * *` | 06:00 | Run `scrape_racecard.py`, commit `racecard_today.json` |
| `scrape-results`  | `30 13 * * *` | 21:30 | Run `hkjc_scraper_github.py` + `merge_csv.py`, commit CSV + `all_results.csv` |

Both jobs use `workflow_dispatch` so they can be triggered manually.

### Token requirement
The workflow needs write access to commit back to the repo. Enable once:  
**Settings → Actions → General → Workflow permissions → Read and write permissions → Save**

### Steps (both jobs)
```
checkout → set up Python 3.11 → pip install → install Playwright Chromium →
run scraper script → git config → git add data/ → git diff --quiet || git commit + push
```

## 7. `index.html` — Production Viewer

### 7.1 Data Loading (replaces hardcoded `D` array from prototype)

On page load, two parallel fetches:

```javascript
const SCRAPER_RAW = 'https://raw.githubusercontent.com/mzf3334-dev/hkjc_scraper/main';

Promise.all([
  fetch(`${SCRAPER_RAW}/data/racecard_today.json`).then(r => r.json()),
  fetch(`${SCRAPER_RAW}/data/all_results.csv`).then(r => r.text()),
]).then(([racecard, csvText]) => { /* parse + render */ });
```

### 7.2 CSV Parsing

```javascript
function parseCSV(text) {
  const lines = text.trim().split('\n');
  return lines.slice(1).map(l => l.split(','));  // skip header, split on comma
}
```

Result is the same row format as the prototype's `D` array — all existing analytics functions work unchanged.

### 7.3 Race Card → Race List

The race list is built from `racecard_today.json` entries (not from the CSV). The CSV provides only analytics context from historical data.

### 7.4 Analytics Functions (unchanged from prototype)

| Function | Input | Output |
|----------|-------|--------|
| `detectPos(incident, gate)` | Single row | `'前'` / `'中'` / `'後'` |
| `typicalPos(horseName)` | Horse name | Most frequent position across all history |
| `jockeyRecord(horseName, jockey)` | Names | `{ wins, total, label, hasWin }` |
| `trainerJockeyWinPct(trainer, jockey)` | Names | `{ label, cls }` |
| `sameDistChips(horseName, dist, excludeDate)` | Names + dist | HTML chip string |
| `buildPrediction(raceRows, dist)` | Race entries | Sorted scored array |

### 7.5 UI (unchanged from prototype)

| Element | Source |
|---------|--------|
| Header date badge | `racecard_today.json → date` |
| Race list (left panel) | `racecard_today.json → races[]` |
| Horse cards (right panel) | `racecard_today.json → races[i].entries[]` + analytics from CSV history |
| All badges, prediction box | Same logic as prototype |

### 7.6 Loading & Error States

| State | Display |
|-------|---------|
| Fetching | Spinner overlay: `載入中…` |
| `racecard_today.json` has no races | Message: `今日沒有本地賽事` |
| Fetch error | Message: `資料載入失敗，請稍後重試` with retry button |

### 7.7 Changes vs Prototype

| Item | Prototype | Production |
|------|-----------|------------|
| Data source | Hardcoded `D` array | Fetched from GitHub raw |
| Race entries | From `D` array (results data) | From `racecard_today.json` |
| `原型 PROTOTYPE` badge | Shown | Removed |
| Loading state | None | Spinner + error handling |

## 8. GitHub Token Setup (one-time, before first Actions run)

1. Go to `github.com/mzf3334-dev/hkjc_scraper` → **Settings** → **Actions** → **General**
2. Under **Workflow permissions**, select **Read and write permissions**
3. Click **Save**

No personal access token needed — the built-in `GITHUB_TOKEN` is sufficient.
